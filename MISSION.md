# Mission: Learn C++ by building Asteroids

## Why
Use this small game as a practical workspace for studying C++. Build each feature personally and explain how its code works.

## Success looks like
- Write a bullet class and explain its constructor and members.
- Manage moving bullets in a vector and remove expired objects safely.
- Explain direction, elapsed time, and the firing cooldown.

## Constraints
- Beginner explanations; guided steps with review before moving on.
- Keep C++17, SFML 2.6.2, and the existing game structure.

## Out of scope
- Collisions, sound, pooling, and unrelated movement changes during shooting lessons.
