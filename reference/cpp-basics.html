Lesson 1

C++ game glossary

Class / object
A class defines a type. An object is an instance of that type, with its own state.
Declaration / definition
A declaration introduces a name and its type. A function definition supplies its body. Our headers declare interfaces; source files define functions.
Constructor
Initializes a new object. It has the class name and no return type. An initializer list after a colon initializes members before the body runs.
Member
A variable or function belonging to a class. Each bullet has its own velocity and shape.
public / private
Public members are accessible to callers; private members are accessible to the class itself and its friends.
const member function
A trailing const makes this object read-only through that function, apart from special mutable members. It can still draw into a separate render target.
Reference (&)
An alias for an existing object. A render-target reference lets drawing use the actual target instead of a copy.
override
Asks the compiler to check that this function replaces a virtual function declared in a base class.
sf::Vector2f
A pair of floats, x and y. Its meaning depends on usage: a position in pixels or velocity in pixels per second.

Sources: C++ constructors, SFML Drawable.
